# Almost Twenty-One

A private, fake-money blackjack game with house credits and uncanny luck.

- No deposits or purchases
- No prizes or cash-out
- No real-value wagering
- Single-file static app

Design direction is based on Kobra's Input OTP component page and shadcn conventions: neutral tokens, segmented modules, compact monospace data, thin dividers, accessible semantic controls, and clear disabled states.
