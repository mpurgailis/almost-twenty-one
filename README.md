# Almost Twenty-One

A private fake-credit blackjack game with occasional absurd dealer outcomes.

## Component provenance

- `src/components/ui/input-otp.tsx` is installed from the public Kobra Systems registry with `npx shadcn@latest add @kobra/input-otp` and used for the pretend-bet control.
- `src/components/ui/navigation-menu.tsx` is installed from Kobra Systems with `npx shadcn@latest add @kobra/navigation-menu` and used in the game sidebar.
- Button, Card, Badge, Separator, and Progress are installed shadcn components.

Kobra source: https://kobra.systems/components/input-otp

No deposits, payments, prizes, cash-out, or real-value wagering.
